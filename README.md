# 🌴 LveSync Portal — Employee Leave Management System

A web-based Leave Management System that allows employees to submit time-off requests and managers to review, filter, approve, or reject applications in real time.

## 🚀 Live Demo
- **Frontend App:** [https://lvesync-portal.onrender.com](https://lvesync-portal.onrender.com)
- **Backend API:** [https://employee-leave-management-9e8e.onrender.com](https://employee-leave-management-9e8e.onrender.com)

---

## ✨ Features

### 👤 Employee Portal
- **Leave Requests:** Submit time-off requests with date ranges and reasons.
- **Date Validation:** Prevents selecting past dates or end dates before start dates.
- **Isolated Leave History:** Employees see only their own leave applications and balance updates.
- **Leave Balance Counter:** Dynamic calculation based on approved leave days.

### 👔 Manager Dashboard
- **Centralized Approval Hub:** View, approve, or reject employee leave requests with custom feedback.
- **Search & Filter:** Real-time search by employee name or reason, plus status filtering (All, Pending, Approved, Rejected).

## 🛠️ Tech Stack
- **Frontend:** Single-Page Application (HTML5, Vanilla JavaScript, Tailwind CSS)
- **Backend:** Python (FastAPI)
- **Deployment:** Render
